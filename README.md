## Entry

**"No Backup"** — *My encryption locks everything I love. I vow to hand you the only key, and no backup.* (85 chars)

## How it works

`main.py` (pure Python stdlib — the grader runs python:3.13-slim with no
site-packages) writes the vow to `/output/entry.txt` and byte-verifies what
it wrote: 85 bytes, 85 chars, inside the 1–160 gate, no trailing newline.
